The ICC profiles in this directory are unmodified files from
[Compact ICC Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles),
released under [CC0 1.0](https://github.com/saucecontrol/Compact-ICC-Profiles/blob/master/license).

- `sRGB-v4.icc`
- `DisplayP3-v4.icc`
- `sGrey-v4.icc`

They exercise profile parsing and color conversion against real ICC v4 files,
in addition to the generated profiles used by the other tests.
